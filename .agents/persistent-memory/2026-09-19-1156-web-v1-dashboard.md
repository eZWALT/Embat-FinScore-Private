# 2026-09-19 11:56 — Health Sentinel web v1

- **Author:** Codex
- **When:** 2026-09-19 11:56 CEST

## What changed

- Replaced the static concept page in `product/web/` with a Next.js 16 App Router application using shadcn/ui and pinned dependencies.
- Added a server-side data boundary: `page.tsx -> getDashboardData -> ScoreRepository -> LocalBundleRepository`. It reads `product/score/sample_bundle` by default; `SCORE_BUNDLE_DIR` can point at another generated bundle.
- Added a company selector, four score summary cards, a line chart for score history, a horizontal bar chart for latest category scores, a localized main signal, metadata and the monitoring disclaimer.
- Added loading and error states, responsive layouts, lint configuration and local run instructions.
- Added Node/Next build artefacts to the root `.gitignore`.

## Decisions

- The browser does not call an internal HTTP API. Server Components read through the repository interface; a future Supabase adapter can replace the local adapter without changing the UI.
- The committed 12-company sample bundle is the v1 data source because the CSV files in this checkout are placeholders; it is genuine output derived from the synthetic local dataset.
- The dashboard uses shadcn's `Chart` wrapper over Recharts and a restrained dark neutral theme.
- `next build --webpack` is used because Turbopack's PostCSS worker cannot bind its internal port in the managed sandbox.
