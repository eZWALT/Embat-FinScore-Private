# How to run a night child (from 00:22 CEST)

Read `overnight/NORTH_STAR.md` first. Scope: analysis / features / explainability.
No `product/`. No 0–100 formula.

You are **long-lived**. Stay on your owned files for **at least 30 minutes** of
real iteration: write → run → read the metric → fix or try the next variant
in the *same* module. Do not exit after the first green run.

When the primary task is done, pick the next experiment that still fits your
owner files (another Y column, a smaller feature set, a leak screen, a plot).
Write one wave note at the end, not after every tweak.

Cap is 3 concurrent. You will not be killed to make room.
